# NFL Predictions — 6-Month Feature Roadmap

## Month 1: Week-Opening Experience (Tuesday)

- **This Week's slate** — All games with model spread, moneyline, and O/U picks with confidence tiers.
- **Injury report integration** — Pull Wednesday practice report; flag key absences (QB, WR1, pass rusher).
- **Weather forecast badge** — Wind speed, temperature, precipitation probability for outdoor stadiums.
- **QB matchup comparison** — Side-by-side QBR, completion %, sack rate for each QB.

## Month 2: Team Analytics

- **Team efficiency dashboard** — DVOA, DVOA rank, O-line PFF grade, pace.
- **Home/away split tracker** — Teams that significantly over/underperform away.
- **Situational stats** — 3rd down conversion, red zone efficiency, 4th quarter performance.

## Month 3: Player Props Enhancement

- **Prop calculator** — Enter player name and stat category; see model probability vs. DraftKings line.
- **Matchup overlay** — Opposing CB rank, safety coverage for WR props; LB coverage for RB receiving.
- **Stack tool** — Identify correlated props (QB passing yards + WR receiving yards from same game).

## Month 4: Historical Analysis

- **Season accuracy tracker** — Spread, moneyline, totals accuracy week by week.
- **Model vs. closing line** — CLV tracking chart since September.
- **Upset finder** — Games where model probability >55% for the dog; historical accuracy of those picks.

## Month 5: Advanced Betting Tools

- **Parlay builder** — Multi-game parlay with combined probability.
- **Same-game parlay calculator** — Correlated prop parlay construction.
- **Kelly bet size widget** — Enter bankroll; get recommended stakes per pick.

## Month 6: Automation

- **Thursday email** — Opening-week preview with top picks.
- **Sunday morning email** — Updated picks accounting for late scratches.
- **GitHub Actions** — Nightly pipeline to fetch ESPN scores, injury reports, model predictions.
